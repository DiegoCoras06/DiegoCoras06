## Proyectos destacados

### 🎓 DETECSER — Sistema de detección de riesgo de deserción estudiantil
Plataforma full-stack para la UNSCH que identifica estudiantes en riesgo de abandono académico mediante un componente de Machine Learning que genera alertas automáticas.
> **Stack:** FastAPI · React + Vite + Tailwind CSS · PostgreSQL (Neon) · Alembic · scikit-learn

---

### Sistema de Gestión del Proceso de Admisión — UNSCH
Diseño de arquitectura de alta disponibilidad para la plataforma de inscripción al examen de admisión, pensada para soportar **15,000 usuarios concurrentes** durante la apertura del proceso.
> **Enfoque:** Arquitectura de software · Alta disponibilidad · Bases de datos

---

### Mapa Alerta Comunitaria
Plataforma de mapeo de alertas comunitarias en tiempo real, con codificación de severidad por colores y autenticación de usuarios, orientada a un caso de uso real en Ayacucho.
> **Stack:** Leaflet.js · Firebase / Firestore · Autenticación

---

### Análisis de datos musicales de Spotify
Proyecto del curso de Inteligencia Artificial I: análisis exploratorio de un dataset de canciones de Spotify, aplicando técnicas de ciencia de datos sobre características musicales.
> **Stack:** Python · Pandas · Machine Learning · Visualización de datos
